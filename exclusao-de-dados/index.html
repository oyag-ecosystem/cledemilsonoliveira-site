Exclusão de Dados

Esta página explica como solicitar a exclusão de dados associados ao site, ao OYAG Ecosystem e às integrações autorizadas, inclusive integrações com serviços da Meta.

Última atualização: 22 de setembro de 2026.

Como solicitar

Envie uma solicitação para contato@cledemilsonoliveira.com com o assunto Solicitação de exclusão de dados.

Informações para localizar o cadastro

Informe somente os dados necessários para identificarmos o registro, como nome, e-mail ou número de WhatsApp utilizado na interação. Se a solicitação estiver relacionada a uma empresa ou workspace, informe também o nome da empresa. Não envie senhas, tokens, códigos de autenticação ou outros segredos.

O que acontece após a solicitação

A solicitação será verificada para evitar exclusões indevidas. Depois da validação, os dados elegíveis serão excluídos ou anonimizados dos ambientes sob nossa responsabilidade, conforme o contexto e as obrigações aplicáveis. Podemos pedir informações adicionais exclusivamente para confirmar a identidade ou localizar os dados corretos.

Dados originados de integrações Meta

Se você interagiu com uma solução conectada ao Facebook, Instagram ou WhatsApp, podemos receber identificadores técnicos, dados de perfil disponibilizados pela integração, metadados de conta e conteúdo de mensagens necessário para executar a funcionalidade solicitada. A exclusão pode ser solicitada pelo mesmo canal indicado nesta página.

Desconectar uma integração

Quando aplicável, o titular ou administrador também pode remover a autorização diretamente na plataforma de origem. A revogação interrompe novos acessos autorizados, mas não substitui uma solicitação de exclusão dos registros já armazenados no OYAG.

Limites de exclusão

Alguns registros podem ser mantidos quando necessários para cumprir obrigação legal ou regulatória, prevenir fraude, preservar segurança, exercer direitos ou manter evidências mínimas de operações legítimas. Nesses casos, o acesso permanece restrito e o uso fica limitado à finalidade de retenção.

Ambientes multiempresa

Em recursos operados para empresas clientes, a solicitação pode envolver dados mantidos no workspace da organização responsável pelo atendimento. Quando necessário, a solicitação será direcionada ao responsável adequado sem ampliar o acesso aos dados para outras empresas.
