Aviso de Privacidade

Este aviso explica, de forma objetiva, como os dados enviados neste site são usados em contatos e agendamentos.

Quais dados podem ser informados

Ao solicitar contato ou agendar uma apresentação, podem ser coletados nome, e-mail, WhatsApp, empresa, segmento, serviço de interesse, mensagem e horário escolhido.

Para que os dados são usados

Os dados são utilizados para organizar o agendamento, responder à solicitação, compreender o contexto apresentado e manter o histórico necessário ao atendimento.

Marketing

O envio de dados para contato ou agendamento não significa inscrição automática em campanhas promocionais. Comunicações de marketing, quando implementadas, devem ter tratamento próprio e opção adequada de preferência.

Armazenamento e acesso

Os registros do agendamento são armazenados na infraestrutura do projeto e o acesso administrativo é restrito aos perfis autorizados do OYAG Ecosystem.

Contato

Para dúvidas relacionadas a estes dados, utilize contato@cledemilsonoliveira.com.
